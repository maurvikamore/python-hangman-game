# Python Chatbot

## About
A Python chatbot that responds to user messages using predefined rules.

## Features
- Responds to greetings
- Handles basic conversations
- Recognizes supported keywords
- Provides interactive responses

## Technologies Used
- Python
- Conditional statements
- Functions
- Strings

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Run:

   python Chatbot.py
